# Decision Trees, Random Forests, and Gradient Boosting

This notebook compares tree-based classifiers on a lending dataset. The task is to predict whether a borrower fully repaid a loan, while also practising exploratory analysis, categorical encoding, model evaluation, and hyperparameter search.

Part of the notebook follows exercises from a machine-learning bootcamp. I have kept it public as a record of my learning process.

## What is included

- exploratory analysis of `loan_data.csv`
- conversion of categorical features into model-ready columns
- train/test splitting
- a single decision tree as a baseline
- random-forest training and evaluation
- gradient-boosting experiments
- confusion matrices, classification reports, ROC/AUC, and cross-validation tools

## Files

- `decision trees , Random forest, gradient boosting/03-Decision Trees and Random Forest Project - Solutions.ipynb`
- `loan_data.csv`

## Running it

Open the notebook in Jupyter and run the cells in order. You will need pandas, NumPy, Matplotlib, Seaborn, and scikit-learn.

## Note

This is an educational comparison on one sample dataset. It is not a deployed credit-risk model and should not be used for lending decisions.
